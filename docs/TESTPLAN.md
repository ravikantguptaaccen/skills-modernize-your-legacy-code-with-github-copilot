# Account Management System Test Plan

This plan captures the current behavior of the COBOL account application for
business-stakeholder validation and future Node.js unit and integration tests.
Unless stated otherwise, start each scenario with a fresh program execution so
the stored balance is initialized to `1000.00`. For scenarios in the same row,
perform the steps in order. Record observed output or balance values in
`Actual Result` and set `Status` to `Pass` or `Fail` after execution.

| Test Case ID | Test Case Description | Pre-conditions | Test Steps | Expected Result | Actual Result | Status (Pass/Fail) | Comments |
|---|---|---|---|---|---|---|---|
| TC-001 | Start the account management application | Application is available to run. | 1. Start the application. 2. Observe the displayed menu. | The application displays the Account Management System menu with options 1 (View Balance), 2 (Credit Account), 3 (Debit Account), and 4 (Exit), and prompts for a choice from 1-4. |  |  |  |
| TC-002 | View the initial account balance | Fresh program execution; balance has not been changed. | 1. Select option `1`. | The application reads and displays `Current balance: 1000.00`. |  |  |  |
| TC-003 | Credit the account with a positive amount | Fresh program execution; current balance is `1000.00`. | 1. Select option `2`. 2. Enter `250.75`. | The application accepts the amount, stores a new balance of `1250.75`, and displays `Amount credited. New balance: 1250.75`. |  |  |  |
| TC-004 | Verify that a credit persists for a later balance inquiry | Credit operation has completed successfully and produced `1250.75`. | 1. Select option `1`. | The application displays `Current balance: 1250.75`, proving the credited balance was written and can be read back. |  |  |  |
| TC-005 | Debit an amount less than the current balance | Fresh program execution; current balance is `1000.00`. | 1. Select option `3`. 2. Enter `125.50`. | The application allows the debit, stores a new balance of `874.50`, and displays `Amount debited. New balance: 874.50`. |  |  |  |
